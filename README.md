# E-Commerce Business Analytics

An end-to-end data analytics project using the Brazilian E-Commerce Public Dataset by Olist.

## Objective

Analyze e-commerce sales, customers, products, payments, deliveries, sellers, and reviews to identify business trends and actionable insights.

## Tech Stack

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SQL
- Power BI
- Git/GitHub
